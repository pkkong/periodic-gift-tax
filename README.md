# 유기정기금 증여 신고 보조

정적 웹앱입니다. 별도 백엔드 서버가 필요하지 않으며 GitHub Pages 같은 정적 호스팅에 그대로 배포할 수 있습니다.

## 로컬에서 열기

브라우저 보안/캐시 차이를 피하려면 로컬 정적 서버로 확인하는 것을 권장합니다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

그 다음 `http://127.0.0.1:4173/index.html`을 엽니다.

## GitHub Pages 배포

1. 별도 GitHub 저장소를 만듭니다.
2. 이 폴더의 파일을 저장소 루트에 올립니다.
3. GitHub 저장소의 `Settings > Pages`에서 `Deploy from a branch`를 선택합니다.
4. `main` 브랜치와 `/ (root)`를 선택합니다.
5. 배포 URL에서 `index.html`이 바로 열립니다.

## 계산 기준

- 유기정기금 평가는 상증세법 시행령 제62조의 “잔존기간에 각 연도에 받을 정기금액” 문구에 맞춰 달력상 수령연도별 금액을 묶어 3.0%로 현재가치 할인합니다.
- 1년분 정기금액의 20배 상한을 적용합니다.
- 관계별 증여재산공제, 과세최저한, 기본세율, 신고세액공제, 세대생략 할증세액을 반영합니다.

세무 신고 보조용 초안 생성 도구입니다. 실제 제출 전 홈택스 최신 화면과 관할 세무서 안내를 확인해야 합니다.
