## Rules

- Never commit `.env`, `.env.local`, API keys, browser cookies, storage-state files, HAR files, downloaded credentials, `.ait` artifacts, `node_modules`, or `dist`.
- Keep `.env.example` committed as documentation only.
- Use GitHub repository or environment secrets only for CI tasks that truly need non-public credentials.
- Prefer `ait token add` for Apps in Toss deploy keys. It stores a profile outside the repository.
- If `.env.local` is used to bootstrap an Apps in Toss token, remove the real key from `.env.local` after registration.
- Do not store HomeTax IDs, passwords, certificates, OTPs, cookies, or session exports in this project.

## Local Apps in Toss Deploy

1. Copy `.env.example` to `.env.local`.
2. Set `APPS_IN_TOSS_API_KEY` temporarily and optionally `APPS_IN_TOSS_PROFILE`.
3. Run:

   ```sh
   npm run ait:token:add
   ```

4. Remove `APPS_IN_TOSS_API_KEY` from `.env.local`.
5. Deploy a built artifact with:

   ```sh
   npm run ait:deploy
   ```

Release review submission may still require the Apps in Toss Console if the CLI does not expose that action.

## Audit Commands

Run before pushing:

```sh
npm run check:secrets
git diff --check
git status --short
```

If `npm` is not available in the current shell, run:

```sh
bash scripts/check-secrets.sh
```

For GitHub-side inventory:

```sh

```
