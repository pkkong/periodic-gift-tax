# 우리 아기 증여 도우미

증여세가 나오지 않는 범위 안에서 자녀 증여 실행과 홈택스 신고 준비를 돕는 정적 웹앱입니다. 별도 백엔드 서버가 필요하지 않으며 GitHub Pages 같은 정적 호스팅에 그대로 배포할 수 있습니다.

배포 주소: https://pkkong.github.io/periodic-gift-tax/

입력값은 서버로 전송하지 않습니다. 기본 상태는 메모리 처리이고, 사용자가 임시저장이나 백업을 선택한 경우에만 브라우저 로컬 저장소 또는 JSON 파일에 남습니다.

## 로컬에서 열기

브라우저 보안/캐시 차이를 피하려면 로컬 정적 서버로 확인하는 것을 권장합니다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

그 다음 `http://127.0.0.1:4173/index.html`을 엽니다.

## GitHub Pages 배포

1. 별도 GitHub 저장소를 만듭니다.
2. 이 폴더의 파일을 저장소 루트에 올립니다.
3. GitHub 저장소의 `Settings > Pages`에서 `Deploy from a branch`를 선택합니다.
4. `main` 브랜치와 `/ (root)`를 선택합니다.
5. 배포 URL에서 `index.html`이 바로 열립니다.

## 계산 기준

- 유기정기금 평가는 상증세법 시행령 제62조의 “평가기준일부터의 경과연수” 문구와 유권해석상 1년 미만 경과기간 제외 취지에 맞춰 수령연도별 금액을 묶습니다. 평가기준일이 속한 연도의 금액은 할인하지 않고, 다음 연도부터 3.0% 복리로 할인합니다.
- 현금 일시증여는 할인 없이 증여일의 현금 증여금액을 평가액으로 봅니다.
- 1년분 정기금액의 20배 상한을 적용합니다.
- 관계별 증여재산공제, 과세최저한, 기본세율, 신고세액공제, 세대생략 할증세액을 반영합니다. 과세표준 50만원 미만 부과 제외 기준 때문에 앱의 무세금 안전 한도는 `공제액 + 499,999원`으로 계산합니다.

세무 신고 보조용 초안 생성 도구입니다. 실제 제출 전 홈택스 최신 화면과 관할 세무서 안내를 확인해야 합니다.
