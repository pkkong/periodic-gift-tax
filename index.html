        신고 방법 자세히 보기
        1. 홈택스에 로그인

          공동인증서나 간편인증을 준비하세요. 미성년 자녀 신고는 화면 안내에 따라 법정대리인 정보가 필요할 수 있습니다.

        2. 증여세 신고 메뉴로 이동

          국세청 안내 기준 경로는 홈택스 → 신고/납부 → 세금신고 → 증여세입니다.

        3. 기본세율 정기신고 선택

          현금 증여와 유기정기금 증여는 특례세율이 아니라면 기본세율 적용 증여재산 신고로 봅니다. 신고기한 안이면 정기신고로 진행하세요.

        4. 기본정보 입력

          증여일, 관할세무서, 증여자와 수증자의 성명·전체 주민등록번호·주소를 입력하세요. 앱에는 앞 7자리만 저장하므로 전체 번호는 직접 확인해야 합니다.

        5. 증여재산 입력

          증여재산 종류와 평가액을 입력하세요.

        6. 공제와 10년 내 증여 확인

          최근 10년 안에 같은 증여자에게 받은 증여가 있으면 합산 여부와 이미 쓴 공제액을 다시 확인하세요. 직계존속은 배우자 증여까지 동일인으로 묶일 수 있습니다.

        7. 첨부자료 제출

          앱에서 만든 PDF와 직접 준비한 가족관계 자료, 이체내역을 첨부하세요. 홈택스 화면 항목명은 개편될 수 있으니 화면의 최신 안내를 우선하세요.

        8. 신고서 제출과 납부

          제출 전 평가액, 공제액, 산출세액, 신고세액공제, 납부세액을 앱 결과와 대조하세요. 납부세액이 있으면 신고기한 안에 납부까지 끝내세요.

        적용 규정

        상증세법 시행령 제62조

        유기정기금은 수령연도별 금액을 경과연수로 할인하되, 1년 미만 경과기간의 금액은 할인하지 않고 1년분 정기금액의 20배 상한을 비교합니다.

        상증세법 시행규칙 제19조의2

        정기금 평가에 적용하는 이자율은 3.0%로 반영했습니다.

        국세청 신고납부기한

        증여받은 달의 말일부터 3개월 이내 신고를 기준으로 신고기한을 계산합니다.

        국세청 세액계산 흐름도

        관계별 증여재산공제, 기본세율, 과세최저한, 신고세액공제, 세대생략 할증을 계산에 반영했습니다.

        국세청 주요서식 안내

        신고서 초안, 평가명세, 약정서 또는 확인서를 PDF 저장용으로 만듭니다. 홈택스 신고 방법은 결과 화면에서 안내합니다.

        백업

        백업 파일 저장은 현재 입력값을 JSON 파일로 저장하는 기능입니다. 백업 파일 불러오기는 그 파일을 다시 읽어 입력칸을 채웁니다.
