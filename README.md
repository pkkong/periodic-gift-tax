# 우리 아기 증여 도우미

아이에게 현금을 증여하려는 보호자가 **세금이 나오는지 먼저 확인하고, 송금과 홈택스 신고 준비까지 이어갈 수 있게 돕는 모바일 웹/PWA**입니다.

- Live: https://pkkong.github.io/periodic-gift-tax/
- Type: 정적 웹앱, PWA, GitHub Pages 배포
- Scope: 한국 거주자 현금 증여, 일시증여 또는 매월 고정액 정기증여
- Privacy: 서버 저장 없음. 기본은 브라우저 메모리 처리, 사용자가 선택할 때만 로컬 저장/JSON 백업

![우리 아기 증여 도우미 대표 이미지](./assets/baby-gift-hero.png)

## 만든 이유

자녀에게 매월 일정 금액을 보내는 정기증여는 실행 자체보다 **현재가치 평가, 공제 한도 판단, 홈택스 신고 준비**가 어렵습니다. 특히 유기정기금 방식은 단순히 `월 납입액 x 개월 수`로만 볼 수 없고, 수령연도별 할인과 증여세 공제, 과세최저한, 세대생략 할증 같은 조건을 함께 봐야 합니다.

이 프로젝트는 사용자가 세무 계산식을 직접 찾지 않아도 다음 순서로 판단하고 실행할 수 있도록 만들었습니다.

1. 보내는 사람과 받는 사람 정보를 입력합니다.
2. 관계와 과거 10년 동일인 증여 여부를 확인합니다.
3. 예상 납부세액이 0원인 범위를 먼저 보여줍니다.
4. 일시증여 또는 매월 정기증여를 선택합니다.
5. 예상 납부세액, 신고기한, 다음 액션, 신고 준비 PDF를 제공합니다.
6. 송금 실행 후 홈택스 신고 순서로 이어갑니다.

## 핵심 기능

### 모바일 중심 입력 플로우

- 한 화면에 모든 폼을 펼치지 않고, 한 항목을 확인하면 다음 항목이 열리는 방식입니다.
- 필수 입력이 끝나기 전에는 다음 버튼을 숨겨, 진행 가능 여부를 명확하게 보여줍니다.
- 모바일 키보드의 Enter/Done은 현재 항목의 확인 버튼과 같은 동작을 합니다.
- iOS Safari 확대 방지를 위해 입력 폰트 크기와 `inputmode`를 조정했습니다.

### 증여세 계산 엔진

- 현금 일시증여와 매월 정기증여를 모두 지원합니다.
- 정기증여는 월 납입액을 수령연도별로 묶고, 평가기준연도 금액은 할인하지 않으며 다음 연도부터 3.0% 복리 할인합니다.
- 1년분 정기금액의 20배 상한을 적용합니다.
- 관계별 증여재산공제, 10년 내 동일인 증여가산, 기본세율, 누진공제, 과세최저한, 신고세액공제, 세대생략 할증을 반영합니다.
- 과세표준 50만원 미만 부과 제외 기준 때문에 예상 납부세액 0원 기준은 `사용 가능 공제 + 499,999원`으로 안내합니다.

### 신고 준비 문서 생성

브라우저 안에서 인쇄/PDF 저장용 서류팩을 생성합니다.

- 신고 준비 표지
- 증여재산 및 평가명세서 초안
- 증여세 신고서 초안
- 선택 보관용 증여약정서 또는 현금 증여 확인서

홈택스 입력 체크리스트는 PDF에 섞지 않고, 결과 화면에서 별도 안내로 제공합니다. 약정서나 확인서는 모든 신고에서 필수 첨부라는 뜻이 아니라 사실관계 정리용 보관자료로 취급합니다.

### 개인정보 보호

- 입력값은 서버로 전송하지 않습니다.
- 기본 상태는 메모리 안에서만 유지됩니다.
- 사용자가 누른 경우에만 브라우저 로컬 저장소 임시저장, JSON 백업, PDF 저장이 실행됩니다.
- 전체 삭제 기능으로 브라우저에 남은 임시 데이터를 지울 수 있습니다.

## 화면 흐름

```text
랜딩
  -> 증여자 정보
  -> 수증자 정보
  -> 수증자 계좌 여부
  -> 최근 10년 동일인 증여 여부
  -> 예상 0원 범위 확인
  -> 증여 방식 선택
  -> 금액/기간 입력
  -> 계산 결과
  -> 송금 실행
  -> 홈택스 신고 안내
```

결과 화면을 마지막으로 끝내지 않고, 실제 사용자가 다음에 해야 하는 **계좌 확인, 송금, 홈택스 신고**로 이어지게 설계했습니다.

## 기술 스택

- HTML, CSS, Vanilla JavaScript ES Modules
- JSDoc 기반 도메인 타입 문서화
- Node.js 내장 테스트 러너 `node --test`
- PWA manifest, service worker
- GitHub Pages 정적 배포
- 외부 백엔드 없음

패키지 매니저나 번들러 없이도 루트 앱이 동작하도록 구성했습니다. 계산 로직은 `src/tax.js`, 문서 생성은 `src/documents.js`, UI 상태 관리는 `src/app.js`로 분리했습니다.

## 프로젝트 구조

```text
.
```

## 로컬 실행

정적 파일 앱이므로 간단한 HTTP 서버만 있으면 됩니다. Safari/Chrome은 `file://`에서 ES module import를 막을 수 있으므로 로컬 파일 직접 열기보다 서버 실행을 권장합니다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 엽니다.

```text
http://127.0.0.1:4173/index.html
```

## 테스트

```sh
node --check src/app.js
node --check src/documents.js
node --test
git diff --check
```

현재 테스트는 다음을 검증합니다.

- 월 200,000원 x 120개월 정기증여 평가액
- 월 250,000원 x 120개월 정기증여 평가액
- 장기 계약의 1년분 정기금액 x 20 상한
- 첫해 잔여기간 미할인, 다음 연도부터 3% 복리 할인
- 현금 일시증여 평가
- 관계별 증여재산공제
- 누진세율, 기납부세액공제, 신고세액공제
- 과세표준 50만원 미만 부과 제외
- 세대생략 할증
- 신고기한 주말 보정
- 출력 문서의 일시증여/정기증여 문구 구분

## UX 구현 포인트

- Toss 앱 같은 모바일 금융 서비스의 밀도와 톤을 참고해, 큰 설명보다 짧은 액션 중심 문구를 사용했습니다.
- 비활성 버튼을 흐리게 보여주는 대신, 진행할 수 없으면 다음 버튼 자체를 숨깁니다.
- 증여세가 나올 수 있어도 사용자를 막지 않고, 경고 후 `이대로 결과 보기` 액션을 제공합니다.
- 주민등록번호는 앞 7자리만 입력하고 뒤 6자리는 마스킹 UI로 표현합니다.
- 금액 입력은 텍스트 입력과 `inputmode="numeric"`을 조합해 모바일 숫자 키보드와 천 단위 콤마 표시를 함께 처리합니다.
- 작은 아기 마스코트는 진행 피드백만 보조하며, 법률/세무 판단보다 앞에 나오지 않도록 제한했습니다.

## 현재 한계

- 홈택스 자동 로그인, 자동 입력, 자동 제출은 지원하지 않습니다.
- 법령과 홈택스 화면은 자동 업데이트하지 않습니다.
- 세무사 판단이나 확정 세액 보증을 대신하지 않습니다.
- 증권사/은행 계좌 개설 제휴, 광고, 수익화 기능은 아직 붙이지 않았습니다.

## 포트폴리오 관점에서의 구현 포인트

- 세금 계산 로직을 UI와 분리하고 테스트로 검증했습니다.
- 개인정보를 서버로 보내지 않는 로컬 처리 구조로 설계했습니다.
- 단순 계산기에서 끝나지 않고, 실제 사용자의 다음 행동인 송금과 신고 준비까지 연결했습니다.
- 모바일 브라우저의 Enter/Done, iOS 확대, GitHub Pages 캐시, `file://` ES module 차이 같은 현실적인 배포 이슈를 반영했습니다.
- 후속 작업자가 같은 피드백을 반복하지 않도록 `AGENTS.md`에 제품 범위, UX 규칙, 계산 규칙, 브라우저 주의사항을 문서화했습니다.

## 안내

이 앱은 세무 신고 보조 도구입니다. 실제 신고 전에는 홈택스 최신 화면, 관할 세무서 안내, 필요한 증빙서류, 본인 상황에 맞는 세무 판단을 별도로 확인해야 합니다.
